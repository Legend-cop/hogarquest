## Animaciones visuales

Esta edición incluye movimiento pensado para niños: entrada suave de tarjetas, botones con respuesta elástica, transiciones entre secciones, barras de progreso animadas, podio ascendente, destellos en el inicio y celebraciones con mascota, confeti, sonido y vibración. Las animaciones respetan la opción del sistema para reducir movimiento.

### Comprobar localmente

```bash
flutter pub get
dart format lib
flutter analyze
flutter run
```

Prueba especialmente el splash, los seis botones inferiores, **HECHA** en Mis tareas y el podio de Ranking.


## Dirección visual Playful Quest
Paleta Aventura alegre (#22C55E, #38BDF8, #FACC15, #FB7185), títulos Outfit, textos Figtree, fondo cálido, tarjetas tipo juguete y navegación elevada. La lógica y los recorridos originales no cambian.
